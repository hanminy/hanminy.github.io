APEX 관제 화면 안내 · 실차 2026년 10월 2일판

관제 화면,
이 순서로 사용하세요.

처음에는 장비 상태와 작업 설정,
두 화면부터 보시면 됩니다.

먼저 스캔하기 달라진 점 설정 순서 멈추는 방법 버튼 뜻
현재 자동 스캔과 자동 굴착은 점검 중입니다.

스캔을 다시 실행했을 때 버킷이 크게 흔들려 정지했습니다. 안정성 확인 전에는 자동 스캔을 다시 실행하지 마세요.

지도와 장비 정보는 연결됐지만, 버킷 위치에 약 13cm 차이도 남아 있습니다.
아래 내용은 버튼과 설정을 익히기 위한 안내입니다. 작업 시작은 검증을 마친 뒤에 진행합니다.

마지막 확인: 2026년 10월 3일 · 실시간 상태 표시는 아닙니다.

처음에는 지형부터 스캔합니다.

장비 상태 → auto (0) → Auto Lidar Scan

장비 상태 탭에서 연결을 확인합니다. 연결이 꺼져 있으면 Start (B)를 누릅니다. 이미 Started라면 다시 누르지 않습니다.

auto (0)을 눌러 자동 제어로 바꾼 다음, Auto Lidar Scan을 한 번 누릅니다. 장비가 좌우로 회전하고 자세를 바꿔 지형을 읽습니다.

현재 자동 스캔 반복 실행은 점검 중입니다. 첫 실행은 약 36초 만에 끝났지만, 두 번째 실행에서 버킷이 크게 흔들려 정지했습니다. 안정성을 확인할 때까지 다시 실행하지 마세요. 정상 동작을 확인한 뒤에는 ‘Scan 완료’를 보고 작업 설정 탭으로 넘어갑니다.

keyboard (9)는 수동 모드입니다. 자동 스캔 전에는 auto (0)을 선택하세요.
자동 모드의 Output: Disabled는 키보드 출력이 꺼졌다는 뜻입니다. 자동 제어까지 꺼졌다는 뜻은 아닙니다.

스캔 중 멈추려면 같은 위치의 ‘정지’ 버튼을 누릅니다. 이미 필요한 지형이 충분히 보이면 매번 다시 스캔할 필요는 없습니다. 스캔 성공과 자동 굴착의 위치 정확도 검증은 별개입니다.

달라진 점은 하나부터 기억하세요.

팔 곳과 버릴 곳을 따로 정합니다.

지도에 사각형을 두 개 그립니다. 두 영역은 서로 겹치면 안 됩니다.

설정은 이 순서로 하세요.

  1. 장비 정보와 지도를 확인합니다.

    위 순서로 스캔 완료를 확인합니다.
    그다음 작업 설정 탭에서 현재 지형을 확인합니다.

    Current는 현재 지형입니다.
    회색이거나 비어 있는 칸은 아직 지형을 모르는 곳이므로 피합니다.

  2. 현재 지형을 목표 지형으로 복사합니다.

    Copy Current → Target을 누릅니다.

    현재 땅 모양을 먼저 복사해 두고, 파낼 곳만 낮추는 순서입니다.
    Target은 작업이 끝났을 때 만들고 싶은 땅 모양입니다.

  3. 팔 곳과 버릴 곳을 그립니다.

    흙을 팔 영역 (굴착·고르기)을 켭니다.
    Current 지도에서 마우스를 끌어 사각형을 그립니다.

    이어서 흙을 버릴 영역 (덤프)을 켜고,
    같은 지도에 겹치지 않는 사각형을 하나 더 그립니다.

    너무 좁게 그리지 마세요. 버킷 폭 60cm와 작업할 길이가 들어가야 합니다. 두 영역의 오류 표시가 없어졌는지도 확인합니다.

  4. 파낼 곳만 선택해 목표 높이를 낮춥니다.

    영역을 그리는 버튼을 끈 뒤, 현재 지도에서 파낼 칸만 선택합니다.

    변화량 Δ를 입력하고 Sel -Δ를 누릅니다.
    예를 들어 0.10m를 넣으면 선택한 목표 지형을 10cm 낮춥니다.

    흙을 버릴 곳까지 함께 낮추지 마세요.
    변경 후 Target과 Difference에서 원하는 곳만 바뀌었는지 봅니다.

  5. 추가 기능은 끄고, 설정부터 확인합니다.

    처음에는 바닥 고르기·다짐·도저 다짐을 꺼 둡니다.

    현재 지도, 두 영역, 목표 높이를 차례로 확인합니다.
    연결 오류나 영역 오류가 있으면 표시된 원인부터 해결합니다.

  6. 검증을 마친 뒤 작업을 시작합니다.

    연결과 위치 정확도 검증이 끝나면 Run Task를 누릅니다.

    지도 여러 장을 모으고 설정을 확인하므로 바로 움직이지 않을 수 있습니다. 버튼을 반복해서 누르지 말고 상태 메시지를 확인합니다.

    현재는 위의 13cm 위치 차이 확인이 먼저입니다. 화면이 열린 것만으로 굴착 준비가 끝난 것은 아닙니다.

멈추는 방법은 꼭 구분하세요.

다른 탭과 이전판 차이도 보고 싶다면
  • AI 모니터: AI가 고른 동작과 작업 진행 상태를 봅니다.
  • 전역맵: 넓은 지형과 저장한 지도를 비교합니다.
  • 주행 제어 / 작업 명령: 이동이나 직접 명령에 쓰는 별도 화면입니다.
  • Trenching (관로파기) 프리셋만 고르고 바로 시작하지 마세요. 이전의 좁은 영역을 위한 값이므로, 두 영역과 버킷 폭을 다시 확인합니다.
  • 흙 버리기 X 위치는 최종 낙하 지점이 아니라 버킷이 열리기 시작하는 위치입니다.
  • AI는 현재 지도 3장을 모아 판단합니다. 지도 수집 중에는 잠시 기다립니다.
  • 관제 화면의 P 키도 Run Task를 켜고 끕니다. 처음에는 화면 버튼으로 상태를 확인하며 사용하세요.
  • 영역은 마우스 대신 Row / Col(행 / 열) 숫자를 넣고 적용할 수도 있습니다.
