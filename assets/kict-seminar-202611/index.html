2.5D height map(elevation map)은 지면을 수평 격자로 나누고 셀마다 높이 추정값과 분산을 저장. 새 점이 들어오면 h ← (σp²·h + σm²·pz)/(σm² + σp²)처럼 분산 가중 평균(칼만 방식)으로 갱신하고, 점 분산은 센서 거리 제곱에 비례하게 둠. 자세추정 드리프트가 곧 지도 왜곡이 되므로 높이 드리프트 보정, ray casting으로 사라진 물체 정리가 필요(Miki et al. 2022, Sec.III). 이 연구는 보행로봇 대상이며 Jetson Xavier에서 다운샘플 약 50 Hz, raw 16 Hz 갱신을 보고.

굴착과의 연결: SNU21(Lee, Jang et al., IROS 2021)은 현재 지표면 형상을 사전 정보로 두고 지표면–버킷 궤적 사이 swept volume으로 굴착량 제약을 걸고, ETH ExT(2025)도 지형 프로파일·최대 굴착깊이 프로파일을 입력으로 사용 — 지표면 지도가 굴착 계획의 기본 입력.

점군은 LiDAR 측정 그대로의 3D 점 집합, NeRF/3DGS는 영상으로 장면을 재구성(Real-to-Sim 용도), occupancy network는 공간 점유 확률 예측. 두 카드의 하단 문구는 원본 그대로이며, 건설 적용 1차 출처는 이번 조사 범위에서 확인하지 않음.

그림 출처: 좌상단 Miki, Wellhausen, Grandia et al., "Elevation Mapping for Locomotion and Navigation using GPU", arXiv:2204.12876 (ETH Zurich RSL), Fig.1 원형. 우상단 그림은 원본 덱 내장(image21.png, (a) Raw Point Cloud → (f) After Surface Reconstruction) — 원 논문 미특정, 외부 배포 시 출처 확인 필요.

모방학습은 숙련자의 (관측, 조작) 쌍을 모아 같은 관측에서 같은 조작을 내도록 학습. BC는 지도학습으로 바로 모방, DAgger는 학습 정책이 도달한 상태에서 전문가 교정을 추가로 받아 누적 오차를 줄임.

Diffusion Policy(Chi et al., arXiv:2303.04137): 최근 몇 스텝 관측(영상·자세) → 앞으로 여러 스텝의 행동 시퀀스를 조건부 잡음 제거로 생성, receding horizon으로 실행. 같은 상황에서 여러 정답 동작이 있는 다봉 분포를 표현. 실기 실험에서 DDIM 추론 10회로 약 0.1 s(RTX 3080). ACT(Zhao, Kumar, Levine, Finn, arXiv:2304.13705): 카메라 4대 + 관절 위치 → 다음 k 스텝 목표 관절 위치를 Transformer+CVAE로 예측, 겹치는 묶음을 가중평균(temporal ensembling). 과업당 시연 50회(10–20분 분량), 50 Hz, 저가 양팔 ALOHA. 두 결과 모두 전동 매니퓰레이터 실내 조작 결과이며, 유압 장비는 명령→속도 지연이 커서 행동 표현과 제어 주기를 별도 설계해야 함. VQ-BeT는 이번 조사에서 원문 미확인(이름만 유지).

굴착 적용 예(외부): ETH ExT(2025)는 RL 전문가(토양 무작위화)·스크립트·제한적 원격조종 시연을 섞어 Transformer를 사전학습한 뒤 SFT/RL 미세조정. 대량 데이터는 사람 시연이 아니라 시뮬 RL 전문가에서 확보.
